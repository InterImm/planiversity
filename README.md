# Planetary University

行星大学网站 · https://planiversity.interimm.org/ (Chinese) and /en/ (English home)

Jekyll, built by GitHub Pages from the `gh-pages` branch. It uses the shared InterImm kit
(https://interimm.org/kit/, source in InterImm/interimm.github.io `kit/README.md`) for colours,
fonts, header, footer and the light/dark switch; `assets/css/planiversity.css` holds only what this site adds.

- Departments: `_data/departments.yml`; interface strings in both languages: `_data/i18n.yml`
- Researchers: `_members/`; registration goes through the GitHub issue template `new_member.md`
- Seminar records: `_articles/`
